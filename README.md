**AndreEletro**

Sistema de logística e controle de estoque para pequenos comércios

## Objetivos

Cadastrar produtos, controlar o estoque e gerenciar pedidos e compras.

# Tecnologias

* React
* Node.js
* Express
* PostgreSQL
* Git
* GitHub

# Funcionalidades

* Cadastro de produtos
* Controle de estoque
* Compras
* Login
* Logout
* CRUD de produtos
* Controle de estoque
* Pedidos
* Dashboard
